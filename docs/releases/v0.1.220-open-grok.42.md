# Open Grok v0.1.220-open-grok.42

This release completes metadata-light OpenCode Go streaming support for
DeepSeek models after live provider verification.

## Provider fix

- **Optional per-chunk model metadata** — accepts trailing Chat Completions
  chunks that omit `model`, in addition to omitted `id`, `object`, and
  `created` fields.
- **Model identity preserved** — content chunks continue to supply the response
  model; metadata-light trailing chunks no longer turn a successful response
  into a serialization failure.
- **Live-provider coverage** — the regression fixture matches the observed
  OpenCode Go sequence: a modeled content chunk followed by a minimal terminal
  chunk.
