# Open Grok v0.1.220-open-grok.39

This release adds direct DeepSeek API support as a first-class provider.

## DeepSeek direct provider

- **Direct API access** — configure a DeepSeek API key from Settings,
  `/login deepseek`, or `DEEPSEEK_API_KEY` and use DeepSeek without an
  intermediary provider.
- **Curated model catalog** — adds namespaced DeepSeek V4 Pro and V4 Flash
  model entries, intersected with the provider's live `/models` response.
- **Provider-isolated authentication** — stored credentials are scoped to
  DeepSeek and are only sent to trusted DeepSeek API hosts. Explicit endpoint
  overrides can use environment-provided credentials without exposing stored
  keys.
- **Live credential updates** — saving or clearing the API key refreshes the
  catalog and safely rebinds loaded DeepSeek sessions without restarting Open
  Grok.
- **Agent integration** — DeepSeek models are available to normal sessions and
  subagents, use direct function tools, and support configurable client-side
  web-search routing.
