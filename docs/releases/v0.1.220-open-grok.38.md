# Open Grok v0.1.220-open-grok.38

This patch release fixes Fireworks AI requests that advertise tools with
unconstrained JSON-valued parameters.

## Fireworks tool-schema compatibility

Fireworks rejected tool definitions containing annotation-only JSON Schema
nodes such as the workflow tool's optional `args` property:

```text
JSON Schema not supported: could not understand the instance
{'description': '...', 'default': None}
```

The Fireworks provider adapter now expands unconstrained schema nodes into an
explicit `anyOf` covering valid JSON value types. Descriptions and defaults
remain intact, already-typed properties are unchanged, and other providers do
not receive this compatibility rewrite.

This restores Fireworks access to the `workflow` tool and protects other tools
that expose arbitrary JSON values through nested properties or definitions.
