# Open Grok v0.1.220-open-grok.36

This release expands the multi-provider model catalog and adds OpenCode Go as
an opt-in provider.

## Provider updates

- **OpenCode Go** — configure its API key from Settings or
  `/login opencode-go`; Open Grok queries the live model API and displays a
  checklist of discovered models.
- **Explicit model enablement** — no OpenCode Go models are enabled by default.
  Only selected models appear in normal model settings and are eligible for
  subagents.
- **Per-model protocol routing** — each OpenCode Go model is mapped to either
  Anthropic Messages with `x-api-key` or OpenAI-compatible Chat Completions
  with Bearer authentication from canonical model metadata.
- **Live settings updates** — credential and enabled-model changes refresh the
  catalog and safely rebind loaded OpenCode Go sessions without a restart.
- **Fireworks AI** — adds Kimi K3 and Kimi K3 Fast to the curated provider
  catalog.
