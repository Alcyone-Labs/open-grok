# Open Grok v0.1.220-open-grok.43

This release brings Open Grok up to date with the latest upstream runtime and
includes the unreleased OpenCode Go streaming fixes prepared after v0.1.220-open-grok.39.

## Reliability and lifecycle

- **Session process cleanup** — reaps bash commands, background tasks, hook
  subprocesses, agent children, and Linux idle inhibitors when their owning
  session or parent process exits.
- **Thread-exhaustion resilience** — startup, filesystem search, and watcher
  paths degrade gracefully instead of crashing when the host cannot create
  another thread.
- **MCP lifecycle hardening** — scopes MCP subprocesses to their sessions,
  improves enable/disable configuration edits, and recovers stuck project
  selections.
- **Storage recovery** — repairs stale SQLite search handles and throttles
  repeated recovery logging.

## Sessions and interface

- **Delete the current session** — adds `/delete` with confirmation and complete
  foreground, dashboard, and session-picker cleanup.
- **Agent Dashboard guide** — documents multi-session navigation, dispatch,
  pinning, search, and keyboard controls.
- **Terminal compatibility** — improves terminal capability detection, Kitty
  keyboard handling, plan/thinking scrollback rendering, and startup behavior.
- **Scheduler and plan ordering** — keeps scheduled loops pinned correctly and
  preserves plan-exit message ordering before queued work resumes.

## Models, tools, and authentication

- **OpenCode Go streaming fixes** — accepts valid Chat Completions chunks that
  omit optional `id`, `object`, `created`, or trailing `model` metadata.
- **Transcript caching** — places cache breakpoints across growing Messages API
  transcripts to reduce repeated prompt processing.
- **Honest wait output** — reports when waits are clamped, avoids inviting
  redundant polling, and delivers stationarity nudges after tool results.
- **Cross-platform auth helpers** — runs provider commands through the native
  platform shell and preserves credentials across concurrent Open Grok
  processes.
- **Access and privacy fixes** — fails open when the remote access gate is
  absent, records coding-data consent decisions, and uses UUID analytics event
  identifiers.
