# Open Grok v0.1.220-open-grok.44

This release fixes the tool and prompt contract used when built-in subagents run
on strict Codex models such as GPT-5.6 Luna and GPT-5.6 Terra.

## Codex subagents

- **Native `apply_patch` support** — writable Codex subagents now receive the
  Codex freeform `apply_patch` tool instead of the Grok Build `search_replace`
  tool.
- **Correct harness prompts** — child model overrides now select the strict
  Codex prompt and tool family after the final child model route is resolved.
- **Capability preservation** — read-only roles remain read-only, and depth,
  workflow, plan-mode, and nested-agent restrictions are reapplied after the
  harness is selected.
