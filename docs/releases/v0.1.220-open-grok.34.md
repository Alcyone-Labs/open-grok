# Open Grok v0.1.220-open-grok.34

This release makes hidden local feature gates discoverable and configurable
from the existing Settings UI, and speeds up GitHub release builds with Cargo
caching on both supported platforms.

## Feature flags in Settings

The Advanced settings page now exposes enable/disable switches for the local
feature gates that are wired into new-session configuration:

- **Memory tools** — enables persistent memory tools and the `/memory`,
  `/remember`, and `/dream` commands.
- **Automatic memory dreaming** — independently controls background memory
  consolidation once memory is enabled.
- **LSP tools** — enables language-server navigation and code intelligence.
- **Web fetch tool** — enables fetching and reading specific web pages.
- **Two-pass compaction** — enables background prefire summaries before
  context compaction.
- **Non-Git workspace warning** — warns when a session starts outside a Git
  repository.
- **Doom-loop recovery** — enables repetitive-output detection and recovery
  retries.
- **Subagent worktree snapshots** — stores completed isolated worktrees as
  durable Git refs for later resume.

Changes are written safely to the matching dotted keys in
`~/.opengrok/config.toml`, preserving unrelated and future configuration.
Settings update optimistically, roll back on write failure, and clearly show
that Open Grok must be restarted before the new session-level gates apply.

TodoGate remains CLI-only because it does not yet have a local config consumer;
the UI does not present a switch that would have no runtime effect.

## Faster GitHub release builds

The Windows x86_64 and macOS Apple Silicon release jobs now restore and save
Cargo dependency and workspace build artifacts with platform-specific cache
keys. Release builders retain their existing targeted metadata clean and still
verify the embedded Open Grok version and exact tagged commit before assets are
published.
