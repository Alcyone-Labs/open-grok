# Open Grok v0.1.220-open-grok.40

This release fixes OpenCode Go streaming compatibility for DeepSeek models.

## Provider fix

- **Id-less stream chunks** — accepts OpenAI-compatible Chat Completions chunks
  that omit the unused top-level `id` field instead of failing with a
  serialization error.
- **No retry loop** — malformed-response retry handling remains unchanged, while
  valid id-less DeepSeek streams complete on the first request.

## Install

```powershell
irm https://github.com/mweinbach/open-grok/releases/latest/download/install.ps1 | iex
open-grok --version
```

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash

```
