# Open Grok v0.1.220-open-grok.33

This release ports two upstream Grok Build monorepo snapshots into Open Grok:
`6e38642` and `47348d1` (upstream package line **v0.2.112**).

## Upstream sync (6e38642)

- **Silent stationarity end-turn** — identical tool thrash and true-noop bash
  end as a success-shaped `StationarityEnded` turn instead of a user-visible
  cancel banner.
- **Fail-closed xAI OAuth refresh** — permanent `invalid_grant` clears the
  tried credential side, sticky short-circuits until login, and wire tokens use
  `current_wire_valid` only (Codex / Kimi / Fireworks stores remain isolated).
- **Leader lock handoff** — flock is acquired before the socket bind, with
  reopen wait and safer zombie-eviction helpers.
- **Failed workflow resume** — `Failed` runs are resumable; journals prune the
  trailing host-error sentinel so the failed host call re-executes live.
  Scratch quotas rise to 10 MiB per file / 64 MiB total.
- **Plugin MCP inheritance** — plugin subagents inherit the parent session’s
  connected MCP pool by default (`mcpInheritance: all`).
- **Live managed MCP refresh** — successful `mcp/list` with `cache=false`
  pushes connectors and search-index updates into live sessions.
- **Pager** — voice interim text merges on submit; watching-cue click opens the
  tasks pane; workflows overlay shows live agent duration, phase follow, and
  Failed resume; quiet confirmed-copy toasts; minimal bash chrome.

## Upstream sync (47348d1 / v0.2.112)

- **Hooks from config.toml** — `[hooks.*]` / `[[hooks.Event]]` layers in user,
  managed, and requirements configs with `HookProvenance` and first-wins dedup
  (`.opengrok` paths preserved).
- **Managed-config signatures armed** — prod verification keys with a trusted-
  origin remote kill-switch and a dark test seam.
- **SessionEnd on quit** — TUI/headless shutdown flushes sessions
  (`SESSION_FLUSH_GRACE`) so SessionEnd hooks can run.
- **Markerless park** — parked turns no longer spam “Worked for” rows; wake
  turns get exactly one terminal marker when appropriate.
- **Coding data sharing lock UI** — ZDR / team non-admin locked settings row.
- **`workspace.export_github`** — GitHub export RPC with Open Grok-branded
  commits and secret exclusion.
- **Protected-edit permission meta** — dual `.opengrok` / `.grok` path
  protection plus path-confined `resolve_file_references`.
- **Lenient MCP config** — broken server stubs become inspect problems instead
  of hard startup failures; OS limits logging and Unix fd soft-limit raise.

## Fork invariants kept

- `$OPENGROK_HOME` / `~/.opengrok` / `.opengrok` isolation
- Multi-provider credentials and routing (xAI / Codex / Kimi / Fireworks)
- Workflows default-on; remote product feature flags still ignored
- Open Grok branding and version scheme (not upstream `0.2.112` package versions)
- Fork-only `agent_swarm` / `/swarm` multi-agent surface
