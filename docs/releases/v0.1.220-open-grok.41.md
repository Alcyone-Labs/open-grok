# Open Grok v0.1.220-open-grok.41

This release completes OpenCode Go streaming compatibility for DeepSeek models.

## Provider fix

- **Optional stream metadata** — accepts OpenAI-compatible Chat Completions
  chunks that omit the unused top-level `id`, `object`, and `created` fields.
- **Strict response content** — model, choices, deltas, usage, and tool-call
  payloads retain their existing validation and conversion behavior.
- **No retry cascade** — valid metadata-light streams complete on the first
  request instead of failing every parallel subagent turn.

## Install

irm https://github.com/mweinbach/open-grok/releases/latest/download/install.ps1 | iex
